## Tracky user stories

Must have
- User can create a new project
- Client/User can create a new ticket
- User can share a project with a client
- User can change the status of a ticket
- User/Client can add comments to a ticket
- Client can accept changes
- User can add testing instructions to a ticket
- User can set a deadline for a ticket
- Client can generate a login link by providing an email address
- User can assign an email address to a project
- Client can view the list of tickets in a project
- Client can view ticket details

Should have
- User can register
- Client can register as a client so they do not have to log in only with a magic link

Could have
- Client can add images to a ticket
- Client can view the change history

Won't have
- User can set up integration with ASANA / JIRA
